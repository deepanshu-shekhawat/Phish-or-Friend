# Third-party assets

The only third-party assets in the CyberDesk library are the three fonts below, all SIL Open Font License 1.1, obtained from the @fontsource npm packages (v5.3.0). Everything else (pixel art, audio, UI) is original work generated by the scripts in `tools/`.

| Font | Use | Source | Licence |
|---|---|---|---|
| Monospace terminal font (VT323) | CSS family `CyberDesk Mono` | https://fontsource.org/fonts/vt323 | SIL OFL 1.1 - `LICENSES/vt323-OFL.txt` |
| Bitmap display font (Press Start 2P) | CSS family `CyberDesk Bitmap` | https://fontsource.org/fonts/press-start-2p | SIL OFL 1.1 - `LICENSES/press-start-2p-OFL.txt` |
| Primary UI font (Pixelify Sans) | CSS family `CyberDesk UI` | https://fontsource.org/fonts/pixelify-sans | SIL OFL 1.1 - `LICENSES/pixelify-sans-OFL.txt` |

## Original work

All pixel-art, sprites, wallpapers, cursors, sound effects and UI components were created for this project. No proprietary logos, artwork or sounds are copied. "CyberDesk" and the emblem are fictional. The visual style is a generic homage to 1990s desktop UIs.
